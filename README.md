# About Bandbook - Social Web for Musicians and Bands
Bandbook is a social music sharing service for the Fediverse. Built for bands, Bandbook is a customizable home page for all your songs, show dates, photos, and announcements. 

## Build with Emissary
Bandbook is a small social app build on [Emissary, the social web toolkit](https://emissary.dev). You must [install Emissary](https://emissary.dev/installation) on a server first, before using Bandbook.

### Installing
To install Bandbook on your own Emissary server directly from this repository, just open your Emissary setup console, navigate to Server Settings > Packages, and add a new Git adapter that points to: https://github.com/EmissarySocial/app-bandbook.git

### Customizing
Bandbook provides a new custom profile page (or, outbox) and templates for a handful of content types to post (galleries, creations, audio, apps), in addition to the new content types provided by Bandbook: galleries, show dates, photos, and announcements.  
After installing, each user can customize the colors, images, and labels used in their own profile.
